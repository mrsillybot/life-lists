# life-lists
Mr Silly: indkøb og opgaver som små JSON-filer (én fil pr. ting). Format og regler: `docs/lists.md` i det private repo `life-automations`.

- `indkoeb/<id>.json`, `opgaver/<id>.json`: varer og opgaver
- `log/<dato>/<barn>-<hash>.json`: børnenes afkrydsning
- `plan.json`: forventede opgaver (skrives af tick)

Skrives af kiosk-appen, telefon-appen og rummene; læses af tick. Ret ikke i hånden uden at vide hvad du gør.
